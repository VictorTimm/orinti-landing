# Orinti landingpage

Onepage website, gebouwd met Next.js (App Router) en Tailwind CSS v4.

## Starten

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structuur

- `app/page.tsx` — homepage met alle secties
- `components/layout` — navbar en footer
- `components/sections` — Hero, Pakketten, Werk, Over mij, Contact

Navigatie gebruikt hash-links (`/#services`, `/#work`, `/#about`, `/#contact`).
